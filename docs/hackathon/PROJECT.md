# Project brief

## Thesis

Every day looks the same until you start looking. LOOK UP 用很小的日常儀式，讓人離開螢幕的注意力競賽，抬頭觀察真實世界，自己判斷什麼值得留下。天空是視覺入口；看不到天空時，抬頭看見的其他真實景象也可以。

核心路徑：**Notice → Capture → Reflect → Connect**。科技在完成這個連結後應退場，不追求停留時間。

## Principles

- Attention over engagement；perspective over popularity；presence over performance。
- WORLD 呈現最近、不同地方的人實際看見的景象，不提供 like、view count、follow、comment、ranking 或 DM。
- 不將 AI 生成圖像當作真實 moment。AI 可以幫開發，無須加入使用者可見的 AI 功能。
- 投稿文字可留白，最多 50 字；不做攝影競賽。

## 本次限制

兩位開發者、120 分鐘、mobile app prototype。成功是同一支手機在約 60 秒內完成一次真實的「選／拍照片 → 寫字 → 公開投稿 → WORLD 看見新照片」體驗。以 [MVP.md](MVP.md) 為本次開發範圍；[docs/PRODUCT.md](docs/PRODUCT.md) 保存長期方向。
