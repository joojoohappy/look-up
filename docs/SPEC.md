# Look up 產品規格 v1

2026-10-23 定案。依據：[Sky × Look up 功能對照與決策](https://claude.ai/artifact/7DXtEHeTKfeiCq73tRFYbb)（9 月 Sky 設計 × 10 月黑客松 Look up 原型）。
本文件取代 `docs/hackathon/` 裡的 MVP 範圍與舊版 PRODUCT.md。功能編號（F-xx）對應 GitHub issue。

## 一句話

Look up 是一個免費、免註冊的 app：抬頭看看天空，拍下來，留一句話，看看世界各地的人此刻眼中的天空。

## 原則

- **注意力，不是互動量。** 沒有按讚、追蹤、留言、排名、瀏覽數、私訊。
- **真實的當下。** 公開到 WORLD 的必須是今天拍的照片（F-08）。
- **免帳號、少資料。** 不需要註冊；不存精確座標；上傳前移除照片 metadata；不做分析追蹤。
- **AI 不取代使用者的表達。** v1 沒有任何使用者可見的 AI 功能。

## 功能

### F-01 開場頁
- 只在第一次打開時出現；之後直接進 WORLD。
- 內容：品牌名、一句邀請、「開始看天空」按鈕、右上角語言切換。

### F-02 WORLD（首頁動態牆）
- 打開 app 的預設畫面，**不需要先發文就能看**。
- **日期列**：最近 21 天，預設今天；可往回看某一天大家的天空。
- **標籤篩選**：「全部」＋ 7 種天空標籤（早上、中午、傍晚、夜晚、山上、海邊、城市），單選，再點一次取消。
- **貼文卡片**：正方形照片、標籤、短語（若有）、`時間 · 城市`（沒地點時顯示「某處的天空」）、社群連結（若有）、「分享」「檢舉」「…（隱藏此發文者）」。
- 下拉重新整理、捲到底載入更多。
- 空狀態：「今天還沒有人分享天空，當第一個吧！」與發文入口。
- 頁尾：聯絡我們／檢舉問題、隱私權政策。
- 頁首有「＋ 分享」按鈕進入 F-03，以及「我的」進入 F-04。

### F-03 發文
1. 拍照或從相簿選一張照片，預覽為正方形（上傳時裁成 1:1）。
2. **短語**：選填，最多 50 字（以 Unicode code point 計，emoji 算 1）。
3. **標籤**：選填，可複選。
4. **地點**：選填開關；開啟時請求定位權限，取得後只保留「城市，國家」文字，預覽「將顯示：台北，台灣」。不儲存座標。
5. **社群連結**：選填，一個完整的 `https://` 網址。
6. **公開或私人**：預設公開；照片不符合 F-08 時只能選私人，並說明原因。
7. **時間**：一律顯示發布時間（不提供隱藏開關）。
8. 顯示「今天還能發 N 則」（F-05）。
9. 公開貼文按「發布」→ 確認視窗「發布後就無法修改」→ 確定後上傳，成功回到 WORLD 今天，新貼文在最上面。
- 錯誤提示：沒選照片、相機或定位權限被拒、連結格式錯、網路失敗（可重試，不重複送出）。

### F-04 我的（MINE）
- 依日期列出自己的貼文：私人的，以及從這台手機發出的公開貼文（標示「公開中」）。
- **私人貼文只存在這台手機**：照片複製到 app 私有目錄，不上傳任何伺服器。換手機或刪除 app 就會消失，畫面上要說明。
- 可刪除自己的貼文（F-06）。

### F-05 每日上限
- 每台手機每個日期最多 **3 則**（公開＋私人合計），日期以手機當地日期計。
- **刪除自己的貼文後，當天額度退還。**
- 公開貼文的上限由後端強制，不能只靠 app 判斷。

### F-06 刪除自己的貼文
- 貼文發布後不能修改任何內容。
- 發文的那台手機可以刪除自己的貼文：公開貼文從 WORLD 與儲存空間移除，私人貼文從手機移除。

### F-07 檢舉與隱藏（App Store 審核準則 1.2 必要）
- 檢舉原因：不是天空照片、令人反感的內容、垃圾廣告或詐騙連結、其他。同一台手機對同一則只能檢舉一次。
- 被檢舉的貼文由站方人工審核下架，目標 24 小時內處理。累積檢舉達門檻時自動先隱藏（門檻待定，建議 3 次）。
- **隱藏此發文者**：在這台手機上不再顯示該匿名發文者的任何貼文（等同封鎖），可在設定中解除。
- 公開聯絡信箱。

### F-08 今天的照片才能公開
- 相機現拍：可公開。
- 相簿照片：讀 EXIF 拍攝日期（DateTimeOriginal），等於手機當地今天才可公開；不是今天、或沒有拍攝日期，只能存成私人。
- 判斷在 app 端，後端另存發文時的當地日期，用於 F-02 的日期列。

### F-09 分享
- 系統分享選單：分享照片與一句話（例如「在 Look up 看到的天空」＋ App Store 連結）。
- v1 不做每則貼文的網頁連結。

### F-10 多語言
- 7 種語言，第一次自動依手機語言選擇，偵測不到時用繁體中文（Sky 設計的做法）；可隨時在開場頁或設定中切換，選擇會被記住。
- 標籤用語言中立的 key 儲存（`morning`…`city`），切換語言不影響篩選。
- 版面以最長的語言（德文、西班牙文）測試。

### F-11 隱私與資料
- 收集：照片（上傳前重新編碼，移除 EXIF/GPS）、短語、標籤、城市文字、社群連結、匿名裝置 ID、發文時間與當地日期。
- 不收集：姓名、email、電話、精確位置、聯絡人、廣告追蹤。
- 隱私權政策（7 種語言至少提供繁中與英文）放在公開網址，app 內與 App Store 頁面都連得到。

### F-12 後端與安全
- Firebase 匿名登入；Firestore `moments` 存公開貼文，Storage 存照片。
- 安全規則：只能用自己的匿名 ID 建立、建立後不可更新、只能刪自己的；欄位格式與長度驗證；照片大小與格式限制。
- App Check：只接受正式 app 的請求。
- 每日上限（F-05）在規則或後端強制。
- 費用：v1 以免費額度為目標，設定用量警示。

### F-13 檢舉處理
- 站方能看到被檢舉的貼文、原因、次數，並一鍵下架或恢復。v1 可先用 Firebase 主控台操作，附操作手冊。

## 資料

**公開貼文**（Firestore `moments/{id}`）

| 欄位 | 型別 | 說明 |
| --- | --- | --- |
| `uid` | string | 匿名發文者 ID |
| `createdAt` | timestamp | 伺服器時間 |
| `localDate` | string | 發文者當地日期 `YYYY-MM-DD` |
| `note` | string | 0–50 code points |
| `tags` | string[] | 0–7 個標籤 key |
| `city` / `country` | string? | 只有城市層級 |
| `link` | string? | `https://` 網址 |
| `imagePath` | string | Storage 路徑，正方形 JPEG |
| `status` | `visible` \| `hidden` | 檢舉處理用 |

**私人貼文**：只存在手機本機，欄位相同，另存照片的本機檔案路徑。

## v1 不做

按讚、追蹤、留言、排名、私訊、瀏覽數、推播通知、每週回顧、使用者可見的 AI 功能、Android 上架（v1 之後）、每則貼文的網頁連結。
